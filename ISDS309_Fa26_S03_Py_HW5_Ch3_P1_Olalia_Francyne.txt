Review Exercise 3.34.3: ••.
Find the errors in the following if statements.

1. if x > 0 then
   	print(x)

Errors: 
	a. If then is not a correct command. Remove "then".
	b. A colon is required at the end of the if header.

Correct:
	if x > 0 :
		print(x)

2. if 1 + x > x ** sqrt(2) :
   	y = y + x

Errors:
	a. Missing parenthesis around equations for better clarity.
	b. The sqrt function is not defined. Import math.

Correct:
	import math
	
	if (1 + x) > (x ** math.sqrt(2)) :
		y = (y + x)

3. if x = 1 :
   	y += 1

Errors:
	a. "=" is an assignment operator while "==" is the relational operator.

Correct:
	if x == 1 :
		y += 1

4. xStr = input("Enter an integer value")
   x = int(xStr)
   if xStr.isdigit() :
   	sum = sum + x
   else :
   	print("Bad input for x")

Errors:
	a. "x = int(xStr)" is executed before checking if xStr.isdigit() is true.

Correct: 
	xStr = input("Enter an integer value")
	if xStr.isdigit() :
		x = int(xStr)
		sum = sum + x
	else :
		print("Bad input for x")

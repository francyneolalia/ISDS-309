Review Exercise 2.26.6: •.
What are the values of the following expressions, assuming that n is 17 and m is 18?

1. n // 10 + n % 10
2. n % 2 + m % 2
3. (m + n) // 2
4. (m + n) / 2.0
5. int(0.5 * (m + n))
6. int(round(0.5 * (m + n)))

1. n // 10 + n % 10 
	= 17 // 10 + 17 % 10
	= 1 + 7
	= 8
2. n % 2 + m % 2
	= 17 % 2 + 18 % 2
	= 1 + 0
	= 1
3. (m + n) // 2
	= 35 // 2
	= 17
4. (m + n) / 2.0
	= 35 / 2.0
	= 17.5
5. int(0.5 * (m + n))
	= int(17.5)
	= 17
6. int(round(0.5 * (m + n)))
	= int(round(17.5))
	= 18

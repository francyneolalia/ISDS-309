Programming Project 2.27.4: ••.
Write a program that prompts the user for two integers and then prints

The sum
The difference
The product
The average
The distance (absolute value of the difference)
The maximum (the larger of the two)
The minimum (the smaller of the two)
Hint: Python defines max and min functions that accept a sequence of values, each separated with a comma.

a = int(input("Enter the first integer: "))
b = int(input("Enter the second integer:))

print("Sum:", a + b)
print("Difference:", a -- b)
print("Product:", a * b)
print("Average:", (a + b) / 2)
print("Distance:", abs(a - b))
print("Maximum:", max(a, b))

PP_2.27.8)
Programming Project 2.27.8: ••.
Write a program that asks the user for the lengths of the sides of a rectangle. Then print

The area and perimeter of the rectangle
The length of the diagonal

import math

length = float(input("Enter the length: "))
width = float(input("Enter the width: "))

area = length * width
perimeter = 2 * (length + width)
diagonal = math.sqrt(length * length + width * width)

print("Area:", area)
print("Perimeter:", perimeter)
print("Diagonal:", diagonal)

Programming Project 2.27.11: ••.
Write a program that asks the user to input

The number of gallons of gas in the tank
The fuel efficiency in miles per gallon
The price of gas per gallon

gallons = float(input("Enter gallons of gas: "))
mpg = float(input("Enter miles per gallon: "))

distance = gallons * mpg

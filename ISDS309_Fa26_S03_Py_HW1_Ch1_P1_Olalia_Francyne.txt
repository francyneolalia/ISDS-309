	accountbalance = 10,000
	months = 0
	interest = 0

	if acountbalance > 0
		interest = accountbalance x 0.005 // interest = 50
		accountbalance = interest + accountbalance // accountbalance = 10050
		accountbalance = accountbalance - 500 // accountbalance = 9550 repeats until 0

	years = months/12
	print("The account is depleted after", years, "years.")

RX_1.21.14)
	Review Exercise 1.21.14: •••.
		To estimate the cost of painting a house, a painter needs to know the exterior surface area. Develop an algorithm for computing that value. Your inputs are the house's width, length, and height; the number of windows and doors; and their dimensions. (Assume the windows and doors have a uniform size.)

	housewidth = input
	houselength = input
	househeight = input

	windows = input
	windowwidth = input
	windowheight = input

	doors = input
	doorwidth = input
	doorheight = input
	
	wallarea = 2(housewidth x househeight) + 2(houselength x househeight)
	windowarea = windows x windowwidth x windowheight
	doorarea = doors x doorwidth x doorheight
	
	exteriorsurfacearea = wallarea - windowarea - doorarea
	print(exteriorsurfacearea)
